# Fork Git et GitHub

## Ajouter au Dépôt de Quelqu'un d'Autre

Au cœur de Git se trouve la collaboration. Cependant, Git ne permet pas d'ajouter du code dans le dépôt de quelqu'un d'autre sans les droits d'accès nécessaires.

Dans les trois prochains chapitres, nous allons vous montrer comment copier un dépôt, y apporter des modifications, puis suggérer que ces changements soient implémentés dans le dépôt original.

À la fin de ces chapitres, vous aurez la possibilité d'ajouter un message à notre page publique sur GitHub : [Page GitHub Publique](https://w3schools-test.github.io/)

## Forker un Dépôt

Un **fork** est une copie d'un dépôt. Cela est utile lorsque vous souhaitez contribuer à un projet existant ou démarrer votre propre projet basé sur celui d'un autre.

Bien que **fork** ne soit pas une commande Git, c'est une fonctionnalité offerte par GitHub et d'autres hébergeurs de dépôts. Commençons par nous connecter à GitHub et créer un fork de notre dépôt.

### Étapes pour Forker un Dépôt

1. Connectez-vous à GitHub.
2. Allez sur le dépôt que vous souhaitez forker :  
   [w3schools-test.github.io](https://github.com/w3schools-test/w3schools-test.github.io)
3. Cliquez sur le bouton **Fork** situé en haut à droite de la page.

Une fois cette étape terminée, vous aurez votre propre copie du dépôt `w3schools-test.github.io` sur votre compte GitHub.

### Fork GitHub Complet

Vous avez maintenant votre propre copie du dépôt `w3schools-test.github.io` et vous êtes prêt à apporter des modifications à votre version locale.
