# Modifier du Code sur GitHub

GitHub permet également d'éditer du code directement via son interface web.

### Éditer un Fichier

1. Ouvrez le fichier souhaité, comme `README.md`.
2. Cliquez sur l'icône de modification (✏️).
3. Apportez vos changements.
4. Ajoutez une description du commit.
5. Sélectionnez "Commit directly to the master branch".
6. Cliquez sur "Commit changes".

Vos modifications sont désormais enregistrées et visibles dans l'historique du dépôt.
