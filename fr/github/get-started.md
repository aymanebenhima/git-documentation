# Démarrage avec Git et GitHub

## Créer un Compte GitHub

Rendez-vous sur [GitHub](https://github.com) et inscrivez-vous.

### Créer un Dépôt sur GitHub

Après connexion, cliquez sur **New Repository**, remplissez les détails et choisissez entre **Public** (visible par tous) ou **Private** (restreint).

### Pousser un Dépôt Local vers GitHub

Depuis votre terminal :

```sh
git remote add origin https://github.com/utilisateur/mon-repo.git
git push --set-upstream origin master
```

Après authentification, vos fichiers seront en ligne. Consultez votre repo sur GitHub pour vérifier.
