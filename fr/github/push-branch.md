# Git et GitHub - Gestion des Branches

## Créer une Nouvelle Branche sur GitHub

Sur GitHub, accédez à votre dépôt et cliquez sur le bouton de la branche actuelle (par défaut "main" ou "master").

Là, vous pouvez créer une nouvelle branche :

1. Tapez un nom descriptif pour la branche.
2. Cliquez sur **Créer une branche**.

La nouvelle branche est maintenant créée et active. Vous pouvez vérifier sur quelle branche vous travaillez en regardant le bouton des branches. Par exemple, si votre nouvelle branche s'appelle **html-skeleton**, ce nom apparaîtra à la place de "main".

### Vérification de la Nouvelle Branche

Une fois la branche créée, vous pouvez commencer à travailler sur un fichier existant dans cette branche.

1. Cliquez sur le fichier **index.html** (ou tout autre fichier pertinent).
2. Commencez à l'éditer directement sur GitHub.

### Prévisualisation et Validation des Modifications

Après avoir modifié le fichier :

1. Cliquez sur l'onglet **Preview changes** pour voir les modifications mises en évidence.
2. Vérifiez que tout est correct.
3. Ajoutez un commentaire expliquant les changements effectués.
4. Cliquez sur **Commit changes** pour enregistrer les modifications dans cette branche.

Vous avez maintenant une nouvelle branche sur GitHub avec des modifications enregistrées ! 🎉
